Beam a file across the room.

One screen flashes a stream of QR codes, another device's camera reads them. No Wi-Fi, no pairing, no upload. Your file never leaves the two devices.

Send Pick a file and show it as a QR stream Receive Point this camera at the sending screen
  1. Open Beamlet on both devices. The receiver can scan the code on the Send page to get here.
  2. On the sender, choose a file and press Start beaming.
  3. On the receiver, press Start camera and frame the code. You can join at any point; missed frames don't matter.
